# AMNIST: AI-Driven Personal Memory Assistant with Real-Time Recognition and Reminders

Final Year Project, BS Software Engineering, HITEC University Taxila (Session 2022-2026).

## About
AMNIST is a mobile app that helps users remember people and tasks using real-time face recognition and smart reminders.

## Features
- Real-time face recognition
- Reminders and notifications
- Secure login with Firebase Authentication
- Cloud storage for user data

## Tech Stack
Flutter, Firebase (Firestore, Authentication, Cloud Storage), MobileFaceNet, OpenCV, Python
